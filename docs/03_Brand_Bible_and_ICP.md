# Urban Heat: Brand Bible & Ideal Customer Profile (ICP) Specification (03_Brand_Bible_and_ICP.md)

**Document Classification:** Brand Governance / Strategy & Positioning  
**Objective:** To establish an immutable, single source of truth (SOT) governing the visual design language, typographic hierarchy, interface mechanics, and Ideal Customer Profiles (ICPs) for the Urban Heat platform.

---

## 1. Core Visual Tone & Brand Identity
Urban Heat explicitly rejects standard, soft consumer-tech trends. The interface treats environmental data as a mission-critical infrastructure asset. The tone is **tactical, scientifically authoritative, minimalist, and ultra-high-contrast.** ## 2. Color Palette (Light Mode Default)
| Element | HEX Code | Design System Application |
| :--- | :--- | :--- |
| **Primary Canvas** | `#F8F9FA` | Foundation background layer. |
| **Surface Container**| `#FFFFFF` | Internal cards and HUD backdrops. |
| **Structural Border**| `#E1E4E8` | Perimeter borders and framing strokes. |
| **Primary Text** | `#0D1117` | Core metrics and bold typography. |
| **Muted Metadata** | `#586069` | Secondary metadata and timestamps. |

### Functional Data Tokens (The Polyline Heat Array)
* 🔷 **Cool Blue (`#3498DB`):** < 75°F
* 🟢 **Temperate Green (`#2ECC71`):** 75°F to 84.9°F
* 🟡 **Thermal Warning (`#F1C40F`):** 85°F to 94.9°F
* 🟠 **Critical Heat (`#E67E22`):** 95°F to 104.9°F
* 🔴 **Extreme Danger (`#E74C3C`):** >= 105°F

## 3. Ideal Customer Profile (ICP)
* **Tier 1:** Grassroots Environmental Justice (EJ) Alliances (e.g., WAWA).
* **Tier 2:** Municipal Sustainability Offices & Chief Heat Officers.
